# Bambook 员工手册

这里存放面向员工的业务操作说明。按任务解释适用场景、办理岗位、准备材料、页面入口、操作步骤、保存结果、交接和常见问题；术语和按钮以当前真实界面为准。不要把模拟企业数据、内部接口说明或走查日志放进员工正文。

`pages/` 为 Markdown 章节，`assets/` 可存经脱敏的真实应用截图。截图、动图应确实帮助理解操作，不能使用真实客户资料；避免用装饰图代替说明。`site/` 为生成的离线阅读版，不入库。

维护者和 Agent 的业务规则、实现链路、权限、验证证据与已知缺口写在 `docs/CODE_WIKI.md` 等现有工程文档，员工手册只引用用户完成工作所需的信息。旧版 `docs/Bambook-操作手册.md` 是历史稿。

## SOP 文字真源

`sop/` 存放按当前业务行为维护的岗位操作文字，由软件实施 Agent 与 Code Wiki 一起更新；教学 HTML 的设计和制作由另行分工的 Agent 负责。文字需写清岗位、开始条件、步骤、结果、交接和异常，HTML 呈现不得把未实现能力补写成可用功能。

- [小竹业务问答 SOP](sop/platform-ai.md)：当前可引用的记录、提问、人工核对与失败恢复。

## 交付与教学标准

员工交付物是 HTML 教学手册。各任务包含明确 SOP：办理岗位、开始条件、步骤、完成标准及下一位接手人。最终目标为各界面和每项操作提供相应指引与演示，需清楚标出点击位置、填写内容和结果；不能用整屏截图跳转代替教学。源文件格式不作为员工阅读门槛。

**2026-10-30 用户最新纠正**：不再使用青屿小组和该库作为操作或展示来源，既有粗糙截图/GIF 已从员工版撤下；只保留作内部复核素材，不得复制进培训包。先使用不连接任何公司库的独立教学案例，明确标为交互演练及简化控件；将来真实界面素材须来自专门整理好的稳定培训场景。不得把交互演练冒充业务操作已执行。

当前有35课、238步、273张实际界面WebP：报价到订单10课；采购与生产12课（成品采购4课，定金归属、生产尺码、产前样送检/评审/确认、放行、进度、完工8课）；采购结算与付款13课。旧六篇内容仅作待完善的参考说明，旧十段GIF不作为已验收教学覆盖。课程素材齐全、播放器可运行、业务流程已验证及员工已能独立上手是分别核验的事实，不能互相替代。

GIF 默认显示静态封面，由读者点击播放或停止。每张动画聚焦一个任务，附动作说明，并可查看原尺寸；分步截图合成的动画注明分步演示，不冒充连续录像。采用 `<名称>-poster.png` 与同名 GIF 配套，二者放在同一素材目录。

## 教学课程与真实界面采集（2026-10-30）

分步教学课程在 `wiki/lessons/*.json`（按 `order` 排序），每课对应一组真实界面采集 `wiki/assets/lessons/<capture>/`：每步一张 2× 截图和要操作控件的位置（`capture.json`），由 `node scripts/manual-capture.mjs <课程>`（或 `chain` 按业务先后采集整条付款链）在本地独立 Mist 服务（`npm run dev:mist`，演示种子，不连接公司库或共享服务器）上实际操作录制；重采前先重置本地数据（删除 `server/private/mist-local/store.json` 并重启）。课程 JSON 写每步的操作、填写、完成后、想一想与出错时，步数必须与采集一致，构建时校验。播放器（`scripts/manual-lesson.mjs`）负责推近、压暗、光标点击 / 输入、气泡、连续播放 / 暂停 / 重播本步和亮起处练习，窄屏按可读性推近。

## 更新与检查

系统顶栏与「我的账号」均提供「使用手册」，在独立页面打开 `/manual/`，不会关闭正在填写的业务表单。Vite开发服务按需生成同一路径；标准Web构建自动把阅读版和引用图片输出到 `dist/manual/`，随同一版本发布，不把课程图片导入业务首屏脚本。离线版仍使用 `npm run wiki:build` 生成 `wiki/site/`，可复制整个目录阅读。

正式Web构建检查课程、采集清单和引用图片均已纳入Git；正式发布还要求整个工作树干净。开发及离线构建可检查未提交稿，不能据此把本机忽略文件或未提交素材带入正式发布包。

1. 用指定模拟公司、相应岗位从真实界面核实入口和步骤；按角色覆盖交接、失败恢复和适用分支。未验证内容不要写成已完成的流程。
2. 更新对应章节，修改 front matter 的 `status`、`sources` 和核验信息。`sources` 必须指向真正运行的相关源码及业务规则，而不是退役 Manager；核验依据另存工程资料。章节只覆盖局部任务时不要声称整个模块已完成。
3. `npm run wiki:check` 分别显示新版课程结构/业务链/核验登记和旧Markdown章节统计。`--strict-lessons` 仅守课程结构、素材、引用和元数据格式，不表示员工培训验收；`--strict` 保留全册模块/旧章节登记及课程结构门禁。旧35模块/6章统计不包含引导课，不能据此计算新版教学完成率；新版覆盖看下文「覆盖矩阵」。
4. `npm run wiki:build` 生成 `wiki/site/index.html` 和素材，可复制整个 `site/` 目录离线阅读。生成器只更新自己负责的文件，不删除目录里其他文件。
5. 对照模拟租户在目标设备检查可读性、目录、搜索、链接和图片，再交付；构建成功不等于视觉和业务已验收。

每章的 `verifiedCommit` 需指向实际核验过的版本，并列出依赖的源码路径。检查结果是辅助提醒，不代替业务复核：路径遗漏、间接依赖、业务规则、权限配置和后端版本均可能导致手册需要更新。

## 课程版本与验收登记

`scripts/manual-catalog.mjs` 是课程结构和登记的读取入口，构建生成 `/manual/manual-version.json`。构建提交与实际采集软件版本分开：素材Git最后变更只记为 `assetRevision`，不能推断成录制时运行的版本。2026-10-31 起全部课程均在应用源码与 82d0a2da 一致时采集并登记该提交；此前素材的采集版本未知，没有倒填。

- 采集文件可声明 `provenance: {softwareCommit, capturedAt}`；提交须为完整40位Git提交，时间为ISO时间。
- 课程JSON可声明 `verification.playback`（`pending` / `passed` / `failed`）与 `verification.employee`（`pending` / `accepted` / `changes-requested`）。播放核验与员工认可独立登记，缺省保持未知。
- 非待处理状态须提供 `checkedAt` 和当前课程的 `contentSha256`；播放核验另需 `softwareCommit`。摘要由目录读取器依据课程内容、采集清单与引用图片生成，排除核验登记自身；内容改变后旧声明自动标为 `stale`，不能沿用原“通过”。员工认可只能根据实际培训验收登记。
- 发布清单仅包含版本、内容摘要和状态，不包含本机绝对路径、账号信息或私有证据。图片使用课程内容摘要作为版本目录，避免新旧课程画面混用。播放等待图片实际加载，失败时提供「重新加载课程」，不会继续空白动画或显示虚假的完成结果。

## 播放核验

`node scripts/manual-playback-check.mjs <课程ID>`（先 `npm run dev:mist`）在真实 Chromium 中只读核验一门课：宽屏逐步画面与热点位置、演示自动播到结果、练习点错只提示与逐步完成、键盘（Enter/Space）、页内链接与搜索、窄屏亮/暗无横向滚动、单张图片失败后的提示与重新加载、控制台无脚本错误；报告与截图写到临时目录。人工看过截图后加 `--register`，在播放器与课程源码已提交时写回 `verification.playback`（提交号、内容摘要、时间）。这只证明播放正常，不代表业务正确或员工已学会。

手册外框跟随应用里本机选择的深浅色（`bambook.device.theme`，未选时跟随系统）；课程截图保持应用浅色原样。

## 覆盖矩阵

教学覆盖以 `wiki/matrix/coverage.json` 为准：每行一项业务任务，登记阶段、主线/分支、岗位、业务模式、当前页面（须在 `pageRegistry.tsx`）、命令（须在命令目录）、课程与文字章节，以及实现依据 `impl`（`walked` 已在当前 Mist 界面走通 / `source` 源码有页面与命令 / `missing` 未交付 / `unchecked` 未核对）。`npm run manual:coverage` 校验引用并检查 [`docs/manual-coverage.md`](../docs/manual-coverage.md) 是否最新；改矩阵或课程登记后用 `node scripts/manual-coverage.mjs --write` 重新生成。

教学状态不手填，由实现依据和课程核验登记推导：待实现、未核对、待录制、播放待验、员工待验、变更后待复核、已验证。文字章节单列，不算已录制；矩阵只给工程与排期使用，不放进员工正文。

练习当前为截图热点及预设输入/选择效果，含问答反馈，可自由跳步，不连接业务库。剩余生产QC（终期）、装箱出运报关、收汇和结汇/退税及各类分支课程、员工上手验收及视频导出尚未完成。
