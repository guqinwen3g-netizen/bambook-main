# Agent 连接与提议确认 SOP

适用于本人使用外部 MCP 客户端连接 Bambook、查看业务、办理普通操作，以及确认或拒绝 Agent 提议。公司管理员开设的长期服务及具体任务，另见[长期 Agent 任务 SOP](agent-tasks.md)。

## 岗位与准备

- 连接由实际业务经办人使用自己的账号创建；具有助手使用权限，并有相应业务模块的查看或办理权限。
- 明确任务目标、业务编号和原始依据。未确认的价格、交期、收付款条件不得交给 Agent 猜测。
- 选择本人信任、支持 HTTP MCP 的客户端。连接配置含访问凭据，仅交给该客户端，不发到群聊或公开文档。

## 创建与使用本人连接

| 步骤 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 打开正确公司，在「我的账号 → Agent 连接」点击「新建连接」。 | 出现连接表单。 |
| 2 | 填写便于识别的连接名称，选择「只读」或「可办理」，创建连接。 | 显示连接地址与凭据导出入口。只读适合核对资料；可办理仍受本人业务权限与审批门禁限制。 |
| 3 | 复制配置，在选定客户端加入并启用。 | 客户端可读取当前授权公司与业务。使用前核对目标公司、账号和原业务编号。 |
| 4 | 先让 Agent 读取当前记录和依据，再提出具体办理要求。 | 普通操作按原业务规则保存；需要本人确认的操作产生待确认提议。 |
| 5 | 回到原业务记录核对结果。 | 保存、提交审批、批准、原邮箱同步及实际收付款分别判断，不能只看聊天中的“完成”。 |

本人短期连接有效期为两小时。它不会增加岗位权限，也不会开放原本无权查看的客户、小组、邮箱或财务记录。

## 确认或拒绝提议

| 步骤 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 在「我的工作 → 接着完成」找到「Agent 提议 · 待确认」，打开对应事项。 | 显示提议内容与执行身份。 |
| 2 | 对照原业务、原件与审批依据，核对准确对象、数量、金额、币种、日期和收发对象。 | 内容足以作出判断；资料不全时先选「稍后」，或拒绝并说明原因。 |
| 3 | 确认内容正确且属于本人职责后，点击「确认执行」。 | 服务端重新检查本人资格、权限、业务范围和原业务门禁；通过后才执行。 |
| 4 | 内容错误、重复、来源过时或不应办理时，填写原因并点击「拒绝」。 | 此提议不执行，原业务保留。需要继续时，让 Agent 重新读取并提出修正方案。 |
| 5 | 返回对应业务模块核对记录、状态及后续交接。 | 提议确认不等于后续审批、到账、投递或工厂实际完成。 |

确认、删除、资金、账务及对外发送等操作需要本人判断。没有足够业务明细或原始依据时，不因 Agent 使用肯定语气而确认。

## 权限与业务范围发生变化

当岗位权限、客户负责人、小组范围或邮箱访问发生变化时，旧提议不能保留新的业务访问入口。来源已不可见时，系统隐藏提议原内容并禁止确认，仍可由本人拒绝。不要借用别人的账号查看或确认；应让当前有权经办人按自己的身份重新核对和办理。

多小组共用的财务记录可能只对本人显示部分明细。不能从旧提议还原全单金额或其他小组资料；需要整单决定时，交给具有完整权限的财务或审批人。

## 续签、撤销与失败恢复

| 情况 | 操作与判断 |
|---|---|
| 连接即将到期或已过期 | 在本人连接列表选择「续签」，将新配置替换到原客户端。旧凭据立即失效，不要让两套配置并行尝试。 |
| 停止使用或怀疑配置泄露 | 立即在本人连接列表「撤销」对应连接，停用客户端中的旧配置。撤销不撤回此前已经保存的业务或已发送的外部请求。 |
| 修改密码或退出全部设备后连接失效 | 重新登录并按当前授权重新建立所需连接，不复用旧凭据。 |
| 客户端提示无权或记录不可见 | 核对本人公司、岗位与业务范围；不能通过重试扩大权限。 |
| 操作超时、返回结果不明 | 先回原业务及「Agent 操作记录」核对原操作，客户端应沿用原操作编号查询或重试；不连续提交同一付款、发送或删除。 |
| 来源已被他人更新 | 重新读取并核对变更，不按过时提议覆盖他人的新结果。 |
| 业务门禁拒绝 | 按提示补齐真实资料或交给正确岗位，不在其他入口绕过审批。 |

「我的账号 → Agent 操作记录」可按本人当前权限查看办理记录与可见变更。历史记录、聊天记录和执行报告都不能代替业务原件及最终状态。
