# 审批签字与电子印章 SOP

适用于合同与资金类审批的手写签字，以及对外单据（CI、PL、PI、SC 等）的电子印章。规则依据：`docs/GO-LIVE.md` 第 1 节「审批手写签字与电子公章（2026-11-05 用户定案）」。

## 哪些审批要签字

批准以下事项时，审批人须在批准窗口里当场手写签字，签字随这一次决定存档。退回、驳回不需要签字。

| 事项 | 办理入口 | 签字位置 |
|---|---|---|
| 订单主单审批、订单变更审批 | 「审批与放行」 | 批准签字 |
| 采购合同审批、采购合同变更审批 | 「审批与放行」或「采购管理」→ 合同详情 → 批准承诺 | 批准签字 |
| 付款申请审批 | 「审批与放行」 | 批准签字 |
| 盘点差异审批 | 「审批与放行」 | 批准签字 |
| 供应商结算确认 | 「财务管理」→ 应付 → 结算 → 确认结算 | 确认签字 |
| 坏账核销、红冲更正 | 「财务管理」→ 应收发票详情 | 核销签字 / 红冲签字 |
| 登记税务机关退税核准 | 「外贸与报关」→ 退税申报详情 → 登记税务核准 | 登记签字 |

报价偏差、QC 让步、开发确认等日常审批不需要签字。

## 手写签字

| 步骤 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 打开审批事项，核对审批内容与随附依据，填写审批意见。 | 意见框已填写。 |
| 2 | 在「批准签字」板上用鼠标、触控板或手写笔签名。 | 笔迹随书写速度变细变粗；右上角出现「重签」。 |
| 3 | 签错时点「重签」。 | 笔迹按书写的反序收回，签字板清空，可重新签。 |
| 4 | 点「批准」。 | 决定与签字一起保存；未签字时提示「请先手写签字」，不会提交。 |

- 签字必须由审批人本人在当时手写，系统不保存可重复套用的签名，也不接受 Agent 代签。
- 由 Agent 起草、需要签字的操作，进入本人「接着完成」后，由本人确认并当场签字。
- 网络中断后核对原请求时，系统按原签字重发，不需要重新签。

## 电子印章：登记与停用（公司管理员）

| 步骤 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 「公司管理」→「印章」→「登记印章」。 | 出现登记窗口。 |
| 2 | 填写印章名称、选择类型（公章、合同专用章、财务专用章、报关专用章、其他）。 | 名称用于签发时识别，例如「雾织贸易公章」。 |
| 3 | 上传透明底 PNG 印章图片（不超过 2 MB）。 | 显示印章缩略图。 |
| 4 | 勾选用印人，至少一人。 | 只有这些人签发单据时能选择这枚章。 |
| 5 | 点「保存」。 | 印章列表出现该章，状态为「启用」。 |
| 6 | 印章遗失、更换或人员调整时，点「停用」并填写原因。 | 状态变为「已停用」，之后不能再用；历史用印记录保留。 |

- 印章图片只有公司管理员和该章的用印人能看到，其他成员只看到名称、类型、用印人和用印记录。
- 调整用印人用「编辑」；人员离岗时应及时移出名单。

## 电子印章：签发时盖章（用印人）

| 步骤 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 「单据中心」→ 选择草稿 → 「生成文件」，核对生成的 PDF。 | 草稿带有系统生成的正式文件；草稿不盖章。 |
| 2 | 点「签发」。 | 用印人会看到「加盖印章」和「用印事由」两项；只能用一枚章时自动选中。 |
| 3 | 选择印章，核对或修改用印事由，点「确认签发」。 | 系统生成盖章版 PDF 作为签发文件，原草稿文件保留在版本记录中，并写入一条用印记录。 |
| 4 | 不需要盖章时，「加盖印章」选「不盖章」。 | 签发文件不带章。 |

- 非用印人签发的单据不带章，签发窗口也不出现印章选项。
- 只有系统生成的单据能盖章；手动上传的外部文件不能盖电子章。
- 用印记录在「公司管理」→「印章」→「用印记录」查看：时间、印章、单据号、用印人、事由。

## 当前状态

- 2026-11-05 本机独立数据副本实测：
  - 采购批准未签字被拒（“请先手写签字”）。
  - 签字图像里带脚本被拒（“签字无效，请重新签字”）。
  - 退回时附带签字被拒（“该操作不需要签字”）。
  - 采购详情手写签字后批准成功，签字存为 SVG 并记入本次决定。
  - 公司管理登记合同专用章（PNG、指定用印人）后，订单「客户单据」生成 PI 选章并填事由，生成的 `-盖章.pdf` 印章叠在授权签字处，用印记录写入。
- 未实测：出运 CI / PL 签发盖章的界面流程（已有服务端测试）、真实部署环境的 PDF 渲染、触屏签字、Agent 提议确认签字的界面流程。
